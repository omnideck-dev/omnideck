Computron 9000 · Mockup Editable Skills & Tool Bundles — v1 design exploration (static prototype)
Skills are now editable. A skill is a reusable instruction (the "skill text") plus an optional set of tool bundles it grants. Built-in skills are starters: edit one and your changes are saved as an override layered on top — the shipped default stays intact and Reset to default restores it any time. You can also author your own skills from scratch.

Tool bundles
Bundles are app-defined groups of related tools. Adding a bundle grants the skill all tools inside it.
Tool bundles are defined in the app and grouped by package / integration. In v1 they're a fixed catalog — not user-editable — but you can assign any of them to a skill. Click a bundle to see the tools it contains.
