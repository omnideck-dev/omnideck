    Tool bundles
    Toggle the bundles this skill grants. Bundles are app-defined groups of related tools. Core tools (scratchpad, file output, sub-agents…) are always available and aren't listed here; integration tools are governed by the Integrations tab.
    Tools come in three tiers. Core tools are always on for every agent. Tool bundles are code-defined groups a skill can grant (curated — not just one per package). Integration tools appear automatically when you connect an integration. Only the middle tier is assignable to skills.
