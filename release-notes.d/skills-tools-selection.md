Choose skills, built-in tools, and individual integrations in one expandable list
when editing an agent. Skill editors use the same tool list, with links to each
integration's approvals. Agents can now select tools without attaching a skill.

Existing broad integration categories migrate once to the matching existing
connections and all their approved tools. For example, an Email selection can
now include approved calendar tools on the same Google connection. New
connections are not automatically added. Exported skills and agents omit local
integration selections so recipients choose their own connections.
