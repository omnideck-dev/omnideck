The agent can now read and change your `custom.css` theme when asked (for
example, "make the accent color purple"), and edits appear in the open app
within a few seconds without a reload. New installs start with a `custom.css`
that lists every overridable color and font, commented out; an existing
`custom.css` is left as it is. Existing installs get the new theme abilities
too.
