Give a chat a goal, and the agent keeps working on it in that chat until it is done. Goals is in early access: on the Settings page, type the early access code, then turn on Goals in Settings → System → Experimental. Start a goal from the composer's + menu or by typing `/goal`. Text after `/goal` fills in the objective. The agent keeps a plan and a short summary of what it knows. It can ask you questions, schedule its own return, or finish the goal. A goal runs with the chat's agent.

The chat header shows the chat's title and, for a chat with a goal, a goal button with its status. The button opens the Goal tab, which shows the status, the plan and its progress, what the agent knows, and goal history. Pause, resume, run now, edit and cancel live there. You can edit a goal only while the agent is not working on it. A finished or cancelled goal can be reopened with a note about what still needs doing. A Goals page in the sidebar lists every chat's latest goal, with search and sorting.

Questions from the agent show as a card in the composer. Answer them one at a time in the message box, or pick a choice, then send the answers together. Answers being sent leave the card. Hide the card to keep chatting, and show it again from the collapsed row. Sent answers quote their question in the chat. Chats waiting for an answer or stopped by an error show in a Needs you section at the top of the conversation list, and each goal chat shows its status under its title.

When a goal run ends with a new outcome, a quiet divider says so in the chat: when the goal resumes, that it is waiting for you, that it stopped on an error, or that it is done. Day headers mark where the day changes in long goal chats. Your own actions, such as pausing or editing, add no divider. When you edit a goal, the agent learns about it at the start of its next run.

Goals and routines each have their own limit on runs at the same time, four each by default. Saved goals, their history and their schedules are stored as files in each chat's folder and survive restarts. Deleting or archiving a chat deletes or archives its goals with it. Turning Goals off stops goal runs and starts no new ones, without changing any goal. Turning it back on picks up where each goal left off.

The chat header now has the sub-agent count, an Artifacts button for the chat's artifacts, and a conversation details button. Routines use an alarm clock icon.

Messages you send while the agent works wait in a strip on top of the message box until the agent reads them. Click one to take it back into the message box and change it, or remove it.
