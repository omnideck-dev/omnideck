The agent can now change the app's colors and fonts when asked (for example,
"make the accent color purple"), separately for light and dark mode. Changes
appear in the open app within moments, without a reload, and are kept across
restarts. The agent can only change appearance settings: colors and fonts, with
values checked for their type. Existing installs get the new theme abilities
too.
