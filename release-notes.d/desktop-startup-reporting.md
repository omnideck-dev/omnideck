Desktop shares startup readiness checks with the bundled CLI and offers Copy
diagnostics on its recovery screen. It can show specific settings-upgrade
failures when reported by the app; existing app versions retain general startup
failure reporting. The bundled CLI is updated to v0.11.0-beta.9. The app image
is unchanged, and this update does not include MCP integrations.
