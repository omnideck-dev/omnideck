Workflows — inline step assistant

every step editor, with the assistant where it actually lives

Every step editor has one ✦ Assistant button in its header. Clicking it opens a strip docked under the header, above the fields — you say what you want, and the answer lands in the editor’s own fields, tinted in the assistant color until you Keep (or Undo). There is no separate assistant view: pickers, trees, and @-references stay exactly where manual editing puts them. Below — each step type where the assistant does real work, in the canonical triage workflow (the API trigger uses the Orders example).
