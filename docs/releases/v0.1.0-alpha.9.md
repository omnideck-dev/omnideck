# omnideck application v0.1.0-alpha.9

This alpha makes first-run setup quieter and clearer across Windows, macOS,
and Linux while keeping required operating-system approval prompts visible.

## Clear setup progress

- Setup now identifies the current step and shows exact progress only when the
  underlying task reports trustworthy values.
- Podman and package-manager installers run in the background where the
  operating system permits it. Windows UAC, macOS administrator approval, and
  Linux PolicyKit prompts remain visible so the user can act on them.
- Windows distinguishes a cancelled UAC prompt from a failure that occurs
  after approval, and it retains the restart-and-resume path for WSL setup.
- Failures keep diagnostics and command output inside the existing
  `Technical details` disclosure. The redundant diagnostic-log button has
  been removed.
- The Ready screen now presents only the completion message and
  `Open omnideck` action.

## Updated application icon

The application icon now uses the blue signal palette consistently across
Windows, macOS, and Linux package formats.

## Updated bundled CLI

Every installer vendors the official OmniDeck CLI `v0.11.0-alpha.1` release.
This CLI adds the structured setup stages, approval classification, background
installer behavior, and technical details consumed by the Desktop setup UI.

## Qualification status

- The Windows x64 NSIS package was exercised from a clean Windows 11 guest
  without WSL or Podman, including UAC and automatic prerequisite setup.
- The x64 DEB and RPM packages were installed, reinstalled, removed, and
  installed again on Debian 13 and Fedora 44. The bundled CLI was also used to
  inspect the Desktop instance and exercise instance creation and lifecycle
  operations.
- Native Apple Silicon macOS installation remains unverified because a clean,
  restorable Apple Silicon test host was not available for this alpha.
- AppImage installation and lifecycle testing were intentionally skipped while
  future Linux packaging is reconsidered. Windows ARM64, Linux ARM64, and Intel
  macOS packages remain build-only coverage in this alpha.

The release workflow still produces the existing Windows, macOS, AppImage,
DEB, and RPM package matrix. Preview packages are unsigned, so Windows may show
a Microsoft Defender SmartScreen warning and macOS may require Control-clicking
omnideck and choosing Open.
