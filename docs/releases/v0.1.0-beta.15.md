# omnideck desktop v0.1.0-beta.15

This beta improves startup checks and makes recovery details easier to share.

## Startup and recovery

- Desktop uses the bundled CLI's readiness checks before opening the app.
- The recovery screen includes **Copy diagnostics** for sharing error details.
- Desktop can show a specific settings-upgrade error when the app reports one.
  Existing app versions continue to use HTTP readiness and general startup
  errors; a completed migration alone never means the app is ready.
- Retrying preserves the installation's configuration and saved data.

## Security

Certificate-verification and networking dependencies have been updated to reject
distrusted certificates and address denial-of-service vulnerabilities.

## Included versions

This release bundles [CLI v0.11.0-beta.9](https://github.com/omnideck-dev/cli/releases/tag/v0.11.0-beta.9).
The app image remains at 0.5.2. MCP integrations and the app-side startup event
producer are not included in this desktop release.

## Upgrading and preview limitations

Install the package for your operating system and architecture over your
existing desktop installation. Configuration and app data are preserved.

macOS packages are Developer ID signed and notarized. Windows packages remain
unsigned and may show a publisher warning. The existing
[Windows WSL compatibility guidance](https://www.omnideck.dev/install.html#windows-wsl-recovery)
still applies.
