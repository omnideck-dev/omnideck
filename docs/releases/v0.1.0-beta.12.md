# omnideck application v0.1.0-beta.12

This beta updates the desktop host and bundled CLI to v0.11.0-beta.6. The
bundled app remains version 0.2.2. MCP integrations are not part of this release.

## Fixed

- Browser sign-in callbacks receive the actual local app address, including
  after port recovery, and Windows host routing is corrected.
- Linux AppImages avoid bundled graphics-library conflicts that can prevent
  the interface from opening on newer Linux systems.
- Windows packages include their required VC++ runtime without requiring a
  separate redistributable installation.
- An app-scoped workaround prevents a WebView2 AI-wallet regression from
  generating invalid Windows sign-in attempts when opening omnideck repeatedly.
  Windows account protection remains unchanged.

## Upgrade

Install the new DEB, RPM, or Windows package over the existing version; replace
the app in Applications on macOS, or replace the Linux AppImage at its existing
path. Existing instances are recreated once to apply the corrected callback
address while preserving their data volumes. You do not need to uninstall first.

## Known limitations

A separate upstream WSL 3.0.1/Podman cgroup regression can prevent Windows
runtime setup or container startup. This release does not fix that upstream
problem or downgrade WSL. See [issue #424](https://github.com/omnideck-dev/omnideck/issues/424)
for the upstream links and tracked follow-up.

Preview packages do not yet carry paid publisher identities. Windows may show
a Microsoft Defender SmartScreen warning, and macOS may require explicit
approval in Privacy & Security.
