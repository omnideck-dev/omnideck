# omnideck application v0.1.0-beta.14

This beta adds Apple Developer ID signing and notarization to the macOS
downloads for Apple Silicon and Intel Macs, and refreshes the desktop icon.
New installations use [app version 0.5.2](https://github.com/omnideck-dev/omnideck/releases/tag/app-v0.5.2).
The bundled CLI remains v0.11.0-beta.6 and is signed as part of the Mac app.

## Security

- Mac apps and installers identify the verified publisher and pass Apple's
  notarization checks before publication. Installers include Apple's ticket
  for offline verification.

## Changed

- The new omnideck icon is used across desktop installers and app windows.

## Upgrade

Install the new DEB, RPM, or Windows package over the existing version; replace
the app in Applications on macOS, or replace the Linux AppImage at its existing
path. Existing data volumes are preserved. You do not need to uninstall first.

## Known limitations

Windows downloads remain unsigned and may show a Microsoft Defender SmartScreen
warning. The existing WSL 3.0.1/Podman cgroup compatibility issue can prevent
Windows runtime setup or container startup; see [issue #424](https://github.com/omnideck-dev/omnideck/issues/424).

The container downgrade protection from beta.13 remains in place. Integrations
already affected by an older downgrade are not automatically repaired; preserve
the vault and migration backups before attempting recovery.
