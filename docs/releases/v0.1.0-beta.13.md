# omnideck application v0.1.0-beta.13

This beta prevents desktop upgrades and repairs from reverting a newer
application container to an older bundled version. New installations use
[app version 0.5.2](https://github.com/omnideck-dev/omnideck/releases/tag/app-v0.5.2).
The bundled CLI remains v0.11.0-beta.6.

## Fixed

- Desktop upgrades and repairs preserve the exact image of a newer installed
  container, preventing an older runtime from rewriting upgraded integration
  metadata.
- The bundled container is updated from 0.2.2 to 0.5.2.

## Upgrade

Install the new DEB, RPM, or Windows package over the existing version; replace
the app in Applications on macOS, or replace the Linux AppImage at its existing
path. Existing data volumes are preserved. You do not need to uninstall first.

If integrations disappeared after an earlier desktop upgrade, this release
prevents another downgrade but does not automatically repair metadata already
rewritten by the older runtime. Preserve the vault and its migration backups
before attempting recovery.

## Known limitations

A separate upstream WSL 3.0.1/Podman cgroup regression can prevent Windows
runtime setup or container startup. See
[issue #424](https://github.com/omnideck-dev/omnideck/issues/424) for the tracked
follow-up.

Preview packages do not yet carry paid publisher identities. Windows may show
a Microsoft Defender SmartScreen warning, and macOS may require explicit
approval in Privacy & Security.
