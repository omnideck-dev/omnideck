# omnideck application v0.1.0-alpha.10

This alpha is a desktop-host maintenance release. It reorganizes the Tauri
host and release-sidecar tooling without intended changes to setup copy,
window behavior, runtime lifecycle, or the application UI.

## Desktop host maintenance

- Bundled CLI execution, output bounds, status parsing, and validation now live
  in a focused module beside their tests.
- Setup records, runtime-port persistence, and image-manifest validation now
  share one durable state-writing path.
- Runtime and application setup events use one forwarding path while retaining
  the existing progress and recovery behavior.
- Sidecar fetching and verification now share manifest loading, checksums,
  target selection, and target-qualified filenames.

These boundaries reduce drift between package tooling and make future desktop
lifecycle changes easier to review. The local Tauri command surface remains the
same four typed commands, and the hosted application still receives no Tauri
capabilities.

## Upgrade behavior

Upgrading from alpha.9 does not reset application data or recreate the Podman
home and state volumes. The desktop host recognizes the new application version
and reconciles the existing environment against the same pinned runtime image.

## Qualification status

- Source policy, setup parity, release-contract unit tests, Rust unit tests,
  formatting, and Clippy pass for the candidate source.
- The hosted release workflow must build all six target architectures and pass
  the ten-package artifact contract before publication.
- Native installation and lifecycle testing has not yet been completed against
  the public alpha.10 assets. Windows ARM64, Linux ARM64, and Intel macOS remain
  build-only coverage until dedicated hardware evidence is recorded.

## Known limitations

Preview packages are unsigned. Windows may show a Microsoft Defender
SmartScreen warning, and macOS may require Control-clicking omnideck and
choosing Open. AppImage and native Apple Silicon lifecycle coverage remain
limited as documented in the desktop testing guide.
