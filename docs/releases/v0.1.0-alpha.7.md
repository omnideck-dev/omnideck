# omnideck application v0.1.0-alpha.7

This alpha gives the application and command line tool one shared way to set
up and manage omnideck. The application bundles Omnideck CLI
`v0.10.0-alpha.1` and uses its versioned JSON interface for runtime setup,
repair, container reconciliation, status, and startup.

## One Podman runtime

The application no longer carries a second set of direct Podman management
commands. On Windows and macOS, both clients use the shared
`omnideck-runtime` Podman machine. On Linux, both use native rootless Podman.
Containers created by either client remain visible and manageable from the
other.

Docker Desktop may be installed for development or other software, but
omnideck ignores it. Podman is the only runtime used for omnideck setup and
container management.

## More reliable setup and repair

- First-run setup, interrupted setup, repair, and updates now reconcile the
  same desired environment through the bundled CLI.
- Existing volumes are preserved when a container must be repaired or
  recreated.
- Windows setup can request a restart, reopen omnideck after sign-in, and
  continue from the saved setup state.
- Setup now provides clearer progress, timeout guidance, and recovery actions
  for WSL, Podman installation, runtime startup, downloads, and port conflicts.
- Container web ports remain bound to loopback, and Windows Podman receives the
  host mapping needed to reach Ollama on the host.

## Native CLI in every installer

Each installer contains exactly one CLI binary compiled for that installer's
operating system and architecture. The release matrix covers Windows, macOS,
and Linux on x64 and ARM64, and verifies the target metadata before uploading
an installer.

## Install

- **Windows 11 x64 or ARM64:** download the matching `.exe`.
- **Apple Silicon or Intel macOS:** download the matching `.dmg`.
- **Ubuntu, Debian, or Linux Mint x64 or ARM64:** download the matching `.deb`.
- **Fedora, RHEL, Rocky Linux, AlmaLinux, or openSUSE x64 or ARM64:** download
  the matching `.rpm`.
- **Other supported x64 or ARM64 desktop Linux distributions:** download the
  matching `.AppImage`.

This preview release is not yet signed. Windows may show a Microsoft Defender
SmartScreen warning and macOS may require Control-clicking omnideck and choosing
Open.

Install this release over an earlier alpha. Preview desktop releases are not
offered automatically.
