# omnideck application v0.1.0-alpha.8

This alpha replaces the Electron desktop shell with a smaller Tauri v2 host
while preserving the existing setup experience and the container-served
omnideck application.

## Same setup, smaller host

- Setup, repair, progress, failure, and Windows restart copy remain identical
  to the previous desktop release.
- The application opens directly into the existing local omnideck environment
  after setup.
- Copy and paste work between omnideck and the host computer, and the hosted
  page can be refreshed with Ctrl/Cmd+R or F5.
- External HTTP and HTTPS links open in the system browser instead of replacing
  the omnideck application window.

## Native CLI on every target

Every installer vendors the official Omnideck CLI `v0.10.0-alpha.2` release
for its operating system and architecture. Release checks pin and verify the
CLI commit, checksums, executable format, target architecture, and SBOM.

## Desktop targets

The release covers Windows, macOS, and Linux on x64 and ARM64. It produces two
Windows installers, two macOS disk images, and AppImage, DEB, and RPM packages
for both Linux architectures, each with a matching SHA-256 file.

This preview release is not signed. Windows may show a Microsoft Defender
SmartScreen warning and macOS may require Control-clicking omnideck and choosing
Open.
