# OmniDeck 0.1.0 Alpha 2

This alpha fixes first-time setup on Windows.

## Fixed

- Podman installer signature verification now passes the downloaded MSI path
  to PowerShell reliably, including paths containing spaces.
- The elevated WSL 2 setup path uses the same reliable handoff.

The Fedora distribution name shown by `wsl.exe --status` is only Windows
reporting the computer's existing default WSL distribution. OmniDeck does not
use or modify it; Podman creates a separate private machine for OmniDeck.

## Downloads

- **Windows 11 x64:** download the `.exe`.
- **Apple Silicon macOS:** download the `.dmg`.
- **Ubuntu, Debian, or Linux Mint x64:** download the `.deb`.
- **Fedora, RHEL, Rocky Linux, AlmaLinux, or openSUSE x64:** download the
  `.rpm`.
- **Other x64 desktop Linux distributions:** download the `.AppImage`.

This release is not yet signed. Windows may show a Microsoft Defender
SmartScreen warning and macOS may require Control-clicking OmniDeck and
choosing **Open** on first launch.

SHA-256 checksum files and GitHub build-provenance attestations are included
for every installer.
