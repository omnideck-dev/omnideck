# omnideck application v0.1.0-alpha.11

This alpha bundles OmniDeck CLI `v0.11.0-alpha.2` and adds disposable local-VM
end-to-end coverage for the shipped Tauri desktop packages. The visible setup
wording, structure, and behavior remain locked to the exact-copy desktop
mockup.

## Desktop and CLI behavior

- The bundled CLI now detects the Windows Podman host gateway correctly when
  the machine address is exposed through SSH configuration rather than the
  default gateway.
- Automated Windows and Linux VM lanes install real packages, launch the Tauri
  host, drive setup and hosted-app journeys, exercise recovery and lifecycle
  actions, and record screenshots, logs, inventories, JSON, and JUnit evidence.
- Each run writes to one disposable evidence folder with a checked-in purge
  command; failed VM overlays and old run folders can be removed without
  touching source or golden images.
- Checked-in manual procedures cover secure-desktop, reboot, trust-warning,
  platform-fit, and other boundaries that cannot be driven reliably.

The runtime container remains pinned to the existing immutable `0.1.0` image
digest because this release changes the desktop host, bundled CLI, and test
harness—not the hosted application image.

## Upgrade behavior

Upgrading from alpha.10 preserves application data and the existing Podman
home and state volumes. The desktop host validates and uses the newly pinned
CLI, then reconciles the environment against the unchanged runtime image.

## Qualification status

- CLI source, vulnerability, six-target build, provenance, SBOM, and portable
  package contracts pass for the public `v0.11.0-alpha.2` release.
- Desktop source policy, exact-copy parity, Rust tests, formatting, Clippy,
  sidecar verification, and the ten-package release contract are release gates.
- Local packaged AppImage and Windows NSIS VM journeys passed for the preceding
  candidate. The alpha.11 package must repeat those lanes with the public CLI
  sidecar before publication.
- macOS, Windows ARM64, Linux ARM64, secure-desktop elevation, reboot, and
  subjective platform-fit remain hardware or manual qualification work as
  documented in the desktop testing guide.

## Known limitations

Preview packages are unsigned. Windows may show a Microsoft Defender
SmartScreen warning, and macOS may require Control-clicking omnideck and
choosing Open. This prerelease is not qualified for promotion until the
remaining platform evidence is completed.
