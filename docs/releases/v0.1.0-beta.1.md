# omnideck application v0.1.0-beta.1

This beta promotes the extensively tested alpha.11 behavior without changing
the setup wording, runtime image, or hosted application. It bundles OmniDeck
CLI `v0.11.0-beta.1`, rebuilt from the same tested CLI source commit as
`v0.11.0-alpha.2`, and corrects the macOS preview package signature.

## Desktop and CLI behavior

- The attended Tauri setup experience and exact-copy wording are unchanged.
- The unattended CLI commands, JSON contracts, runtime lifecycle, and recovery
  behavior are unchanged from the tested alpha.11 source.
- Windows and Linux lifecycle evidence from alpha.11 carries forward because
  those product and package inputs did not change. Release-sensitive source,
  supply-chain, install, and launch checks run again for the beta artifacts.

## macOS packaging correction

The alpha.11 Apple Silicon DMG contained an executable-only linker signature.
Strict bundle verification reported an unbound `Info.plist` and no sealed
resources, causing macOS to describe the application as damaged. Beta.1 uses
Tauri's complete bundle-level ad-hoc signing. Both macOS build lanes mount the
generated DMG and require the contained application to pass strict recursive
`codesign` verification before the artifact can be published.

The ad-hoc signature proves bundle integrity but does not establish an
Apple-verified publisher identity. macOS may still require testers to approve
omnideck in Privacy & Security. Developer ID signing and notarization remain a
stable-release requirement.

## Runtime and upgrade behavior

The hosted runtime remains pinned to the existing immutable `0.1.0` container
release. Updating from alpha.11 preserves the Podman machine, application data,
and named runtime volumes, then reconciles them against the unchanged image.

## Qualification status

- CLI source, vulnerability, six-target builds, SBOMs, provenance, and native
  portable contracts are release gates for `v0.11.0-beta.1`.
- Desktop source policy, exact-copy parity, Rust tests, formatting, Clippy, six
  sidecars, ten package contracts, checksums, and attestations are release
  gates for this tag.
- The public beta package is qualified with the disposable Ubuntu AppImage,
  Debian DEB, Fedora RPM, Silverblue atomic, and clean Windows VM lanes.
- Native macOS and available ARM64 execution remain recorded separately from
  hosted cross-build and static artifact coverage.

## Known limitations

Preview packages do not yet carry paid publisher identities. Windows may show
a Microsoft Defender SmartScreen warning, and macOS may require explicit
approval in Privacy & Security. Those trust warnings are distinct from package
corruption, invalid signatures, or application launch failures.
