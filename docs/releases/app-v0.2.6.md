# omnideck app 0.2.6

## Added

- **Browser:** Save Browser sign-ins as named profiles and choose which profile each agent can use. Browser state changes remain temporary until you explicitly save them, and agents browse in isolated copies that never overwrite a saved profile. Profile settings can remove one saved site or clear all saved state without deleting the profile.

## Fixed

- **Browser:** Browser tab thumbnails now use a consistent, roomier size without long website names stretching individual cards out of alignment.
