# omnideck 0.1.0 Alpha 1

This is the first experimental omnideck application release for Windows,
macOS, and Linux. Install omnideck, open it normally, and the guided setup
prepares the private local workspace. No container or command-line knowledge
is required.

## Downloads

- **Windows 11 x64:** download the `.exe`.
- **Apple Silicon macOS:** download the `.dmg`.
- **Ubuntu, Debian, or Linux Mint x64:** download the `.deb`.
- **Fedora, RHEL, Rocky Linux, AlmaLinux, or openSUSE x64:** download the
  `.rpm`.
- **Other x64 desktop Linux distributions:** download the `.AppImage`.

Each installer contains the matching fixed omnideck application image. The
first launch does not download omnideck from a container registry. macOS and
Windows still prepare a small private Linux workspace required to run the
application.

The same release remains available to CLI users as the multi-architecture
`ghcr.io/omnideck-dev/omnideck:0.1.0-alpha.1` image.

## First-launch notes

- Setup can take several minutes. Agent Dash is included on the setup screen:
  press Space, W, the Up arrow, or click to jump.
- Windows might enable WSL 2 and require one restart before setup can continue.
- macOS might request an administrator password while installing the required
  system component.
- Linux might display a graphical system-permission prompt if Podman is not
  already installed.

## Unsigned alpha

This initial test release is not yet signed:

- On macOS, open the DMG, drag omnideck to Applications, then Control-click
  omnideck and choose **Open** the first time.
- On Windows, Microsoft Defender SmartScreen can show an unknown-publisher
  warning. Choose **More info**, verify that the download came from this
  repository, and select **Run anyway**.

SHA-256 checksum files are attached for every installer, and GitHub records
build-provenance attestations for the release artifacts.

Please report setup failures with the operating-system version and the
diagnostic log available from the setup error screen.
