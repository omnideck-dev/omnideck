# omnideck application v0.1.0-alpha.4

This alpha makes first-time setup, environment upgrades, interrupted setup,
and recovery behave as distinct flows.

## What changed

- New installations open directly to Welcome without showing a preliminary
  checking screen.
- Setup uses one continuous **Preparing your environment** step for required
  downloads and installation, followed by **Finishing setup** and one Ready
  screen.
- Completed healthy installations open omnideck directly without briefly
  displaying setup.
- Installing a newer application only shows the update flow when its pinned
  environment image changed. A wrapper-only update using the same image opens
  directly.
- Interrupted setup is recorded and resumes automatically. Verified downloads,
  image layers, and persistent user volumes are reused when possible.
- Setup failures now show diagnostics backed by the checks that actually ran.
  Checks blocked by an earlier failure are explicitly shown as not checked.
- The setup screen uses the lowercase `omnideck` product name throughout.

The release remains pinned to an immutable multi-architecture environment image.
The application downloads that image during preparation instead of bundling it
inside each installer.

## Test builds

The repository now includes guarded release-test scripts for macOS, Linux, and
Windows. They can download the newest or a selected release and launch isolated
first-run, interrupted, update, returning-user, or doctor scenarios.

The reset actions are limited to a named `release-test` environment and require
confirmation. They do not uninstall Podman, disable WSL, or remove standalone
CLI data.

## Install

- **Windows 11 x64:** download the `.exe`.
- **Apple Silicon macOS:** download the `.dmg`.
- **Ubuntu, Debian, or Linux Mint x64:** download the `.deb`.
- **Fedora, RHEL, Rocky Linux, AlmaLinux, or openSUSE x64:** download the
  `.rpm`.
- **Other x64 desktop Linux distributions:** download the `.AppImage`.

This release is not yet signed. Windows may show a Microsoft Defender
SmartScreen warning and macOS may require Control-clicking omnideck and choosing
Open.
