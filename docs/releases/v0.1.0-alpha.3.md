# omnideck 0.1.0 Alpha 3

This alpha prevents the desktop application's container logs from growing
without a limit and makes application downloads smaller.

## Changed

- Installers no longer contain a copy of the omnideck container image.
- On first launch, omnideck downloads the exact image tested for this release.
  The image is pinned by its immutable SHA-256 digest and reused on later
  launches.

## Fixed

- Podman now caps the omnideck application container log at 150 MB.
- Updating from an earlier desktop alpha recreates the application container
  with the bounded logging configuration while preserving saved data.

## Downloads

- **Windows 11 x64:** download the `.exe`.
- **Apple Silicon macOS:** download the `.dmg`.
- **Ubuntu, Debian, or Linux Mint x64:** download the `.deb`.
- **Fedora, RHEL, Rocky Linux, AlmaLinux, or openSUSE x64:** download the
  `.rpm`.
- **Other x64 desktop Linux distributions:** download the `.AppImage`.

This release is not yet signed. Windows may show a Microsoft Defender
SmartScreen warning and macOS may require Control-clicking omnideck and
choosing **Open** on first launch.

SHA-256 checksum files and GitHub build-provenance attestations are included
for every installer.
